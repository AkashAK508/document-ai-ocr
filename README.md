Document AI OCR processes a PDF through multiple stages:

1. PDF validation and page analysis
2. Direct text extraction from digitally generated PDFs
3. OCR processing for scanned pages
4. Document type classification
5. Date and metadata extraction
6. Keyword-based information retrieval

   ## Requirements

- Python 3.10 or later
- Tesseract OCR
- PyMuPDF
- Pytesseract
- Pillow
